# Сверка экранов с макетами

Офлайн-стенд: HTML-макеты (`mockups/C-*.dc.html`) рендерятся в эталонные PNG, RN-экраны рендерятся через react-native-web в том же Chromium, потом картинки сравниваются попиксельно. Интернет и `npm install` не нужны: пакеты берутся из `/home/claude/webkit/node_modules`, шрифты Geist / Geist Mono подключаются локально.

## 1. Эталоны

```sh
python3 design/tools/render-mockups.py            # все C-* макеты
python3 design/tools/render-mockups.py C-Wishes   # выборочно
```

Результат: `reference/<Имя>.light.png` и `reference/<Имя>.dark.png`, 390×844, масштаб 1. Левый телефон макета светлый, правый тёмный. Скругление 20px и обводку рамки телефона скрипт убирает, потому что приложение рисует экран на весь дисплей. Флаг `--keep-frame` их оставляет. Если какой-то шрифт не загрузился, скрипт падает с ошибкой.

## 2. Регистрация экранов

Нужен файл-реестр, который экспортирует `screens`:

```tsx
import { WishesScreen } from '@/screens/Wishes';
export const screens = {
  'C-Wishes': ({ theme }: { theme: 'light' | 'dark' }) => <WishesScreen />,
};
```

Ключ совпадает с именем макета. Тема приходит в пропсах, и ещё она выставлена как `prefers-color-scheme`, так что `useColorScheme()` / `useColors()` тоже её видят. Можно экспортировать и просто `default`-компонент.

Как работает сборка (`harness/bundle.mjs`): TS/TSX транспилируются через `typescript`, модули резолвятся относительно файла, по `paths` из ближайшего `tsconfig.json` (`@/*` в `mobile/`), через `node_modules` и затем через комплект из `webkit`. `react-native` подменяется на `react-native-web`. Нативные модули (expo-router, expo-haptics, expo-audio, reanimated, gesture-handler, safe-area-context, zustand и т.п.) заменяются заглушками из `harness/stubs/`. Если модуль не найден, подставляется `_auto.js` и в консоль пишется предупреждение. Когда экрану нужно реальное поведение, добавьте файл `stubs/<пакет>.js` (для подпути: `stubs/<пакет>__<подпуть>.js`).

Шрифты: `fontFamily: 'Geist'` или `'Geist Mono'` вместе с `fontWeight` (Geist 400–700, Mono 400–600). Имена expo-google-fonts (`Geist_600SemiBold`, `GeistMono_400Regular`) тоже работают.

## 3. Рендер и сравнение

```sh
node design/harness/run.mjs <registry.tsx> [Экран …] [--theme light|dark] [--crop y0,y1] [--tol 8]
# пример:
node design/harness/run.mjs design/harness/sample/registry.tsx C-Wishes --crop 0,120
```

Команда собирает бандл, снимает `out/<Экран>.<тема>.png` и печатает таблицу расхождений. Повторно сравнить уже снятые картинки можно без рендера:

```sh
python3 design/tools/compare.py C-Wishes --crop 0,120
python3 design/tools/compare.py --all
```

Пиксель считается несовпавшим, если хоть один канал RGB отличается больше чем на `--tol` (по умолчанию 8). Порог 24 слишком мягкий: панель `#F4F3EF` на фоне `#E7E6E1` отличается всего на 13 и при таком пороге пропадает незамеченной. `--crop y0,y1` дополнительно считает процент для горизонтальной полосы. `out/<Экран>.<тема>.compare.png` склеен из трёх панелей: эталон | рендер | дифф (красным отмечены расхождения, голубой рамкой полоса `--crop`).

Пример: в `harness/sample/` сделана только шапка C-Wishes. Полоса 0–120 совпадает на 0.00% в обеих темах (пиксель в пиксель даже при `--tol 0`). По всему экрану расхождение 34.1% в светлой и 32.5% в тёмной, это ниже шапки, где ничего не реализовано. Сдвиг заголовка на 1px даёт 1.5% в полосе.

## Приёмка

- Цель: **≤ 2%** на экран для каждой темы после полной реализации.
- Цифра не заменяет просмотр: всегда открывайте `compare.png`. 2% могут оказаться сдвинутой иконкой или не тем цветом текста, и это ошибка. Сплошная красная зона значит, что блок отсутствует или съехал.
- Шапку и другие блоки удобно проверять отдельно через `--crop`. Для них цель около 0%.

## Ограничения

- Сравнивается RN-web в Chromium, а не iOS/Android. На устройстве растеризация текста, метрики шрифта (`includeFontPadding` на Android), тени и `elevation`, толщина 1.5px-границ и SVG будут немного другими. Финальную проверку делайте глазами на устройстве.
- В макетах обычный CSS: у `div` по умолчанию `content-box`, у `button` UA-стили (`border-box`, свой padding). В RN всё `border-box`. `letter-spacing` в `em` переводите в px (0.08em × 10px = 0.8). `line-height: normal` по умолчанию совпадает с RN-web, только если `lineHeight` не задан.
- Снимается один кадр 390×844: что ниже скролла, не проверяется. Анимации из заглушки reanimated сразу показывают конечное состояние, отступы safe area равны 0 (макеты начинаются с y=0).
- Заглушки (`stubs/`) не обращаются к сети и хранилищу. Данные для экрана берите из моков в реестре.
- `out/` не коммитится (см. `.gitignore`), `reference/` коммитится.
