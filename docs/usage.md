# Usage guide

How «Кстати» is used once it is installed and connected to a server. Interface texts are in Russian; they are quoted as they appear.

## First launch

1. **Sign up:** «Создать аккаунт» → email → «Получить код» → type the 6-digit code into the cells (it is checked as soon as the last digit is entered) → name, password and its repeat. The password must rate at least «Средний» on the strength meter and the repeat must match.
2. **First group:** create one (name + category: Пара, Семья, Родители, Друзья, Другое) or join by a 6-character invite code from someone else.
3. Invite others from group settings: tap the group name in the header → «Настройки группы». Only the owner and admins see the invite code.

Signing in later: email + password. «Забыли пароль?» follows the same steps: email → code → new password and repeat.

## The four lists

| Tab | What lives there | Who sees it |
|---|---|---|
| **Дела** | tasks and plans: date, time, end, repeat, participants, reminders, sub-tasks | the current group |
| **Хочу** | your wishlist: title, note, link; “received” mark | you edit; people from your groups see it |
| **Смотреть** | movies, series, cartoons, shows, stand-up with genres, origin (наше / зарубежное) and year; “watched” mark | the current group |
| **Идеи** | topics with ideas; «Без темы» for loose notes | you; a topic can be opened read-only to groups |

Rows: tap to open, swipe right to mark done/watched, swipe left to delete. A done task stays in place for ~1 s before moving to «Выполнено», and tapping again cancels. Deletions show an undo toast for 5 seconds. Swipe down from the top of any screen to refresh.

An idea can be copied into a task, a wish or a movie; the idea itself stays in its topic.

## Voice

Tap the mic (or hold it, depending on avatar → «Настройки приложения» → «Кнопка микрофона») and say one short phrase, up to 10 seconds. A card appears; nothing changes until you confirm it.

| You say | Result |
|---|---|
| «В субботу в семь ужин у родителей» | new task, Sat 19:00 |
| «Футбол в среду с 19 до 21», «Баня в субботу в 15 на два часа» | task with an end time |
| «Мы с Кариной едем в Питер с 7 по 9 октября» | multi-day task (plan) for two people |
| «В поездку в Питер добавь Эрмитаж в пятницу в 10» | sub-task of the plan |
| «Баня каждую субботу», «По будням зарядка в 8 утра» | repeating task |
| «Хочу новые наушники», «Хочу посмотреть мультик Шрэк» | wish / watch item (cartoon) |
| «Запиши идею: в виджете показывать погоду» | idea, placed into a matching topic |
| «Перенеси дачу на воскресенье», «Продли футбол до 21», «Добавь Карину в футбол» | “was → becomes” card |
| «Мы посмотрели Интерстеллар», «Верни дачу», «Удали ужин у родителей» | mark / unmark / delete |
| «Что-нибудь смешное зарубежное» | Смотреть with filters |
| «Что подарить Маше?» | Маша's wishlist |
| «Какие у нас с Кариной планы на субботу?», «Когда у нас дача?» | list of matching tasks |
| «Покажи идеи для подарков» | opens the topic |

Tips:

- If the transcript is wrong, tap it in the card, fix the text and re-parse — this does not record again.
- When several records match («забрать» → «Забрать посылку», «Забрать документы»), the card asks which one.
- If the phrase is not understood, the card offers to add it as a task, wish or movie.
- Recording on an open plan or idea topic puts the result there.
- Each person has a daily limit of voice commands (30 by default); the counter resets at midnight Moscow time.

## Calendar

Дела switches between a list and a calendar (icons in the header).

- **Pinch** changes the scale: day ↔ week ↔ month ↔ year. **Swipe** left/right moves to the next or previous period. Tapping a day header in the week opens that day.
- Each person has a color (avatar in the header → big avatar → «Цвет»: «Авто», a palette color or any hue from the spectrum). Tasks are drawn in their people's colors; shared tasks carry all of them.
- The colored tabs on the right edge filter the calendar to one person; tap again to show everyone.
- Overlapping tasks split the column into lanes by person; tasks without time sit above the grid; tasks longer than 24 hours are a bar across their days.
- A plan (a multi-day task with sub-tasks) opens as its own screen: sub-tasks on a time grid or as a checklist. In the list view, plans expand to show their sub-tasks.

## Reminders

Avatar → «Настройки приложения» → «Напоминания» → «По умолчанию» sets defaults separately for timed tasks («Дела со временем») and all-day tasks («Дела на весь день»), e.g. 2 hours before, the day before at 20:00, a month before. Any task can override them for you only. Reminders are local notifications, so they work offline; a closed app picks up tasks added by others on its next background refresh (every 15–30 minutes, as the OS allows).

## Widget

Add the «Кстати» widget to the home screen: it shows the nearest tasks and a mic button that opens the app straight into recording. On Android, long-press the widget → configure colors and the mic; on iPhone, “Edit widget”. The lock-screen widgets on iPhone show the mic or the next two tasks.

## Activity

The bell in the header opens what other members did over the last 30 days: tasks, watch items and wishes added, completed or deleted, task edits, members joining, leaving or removed, group renames and topics shared. A dot on the bell means there is something new.

## Common problems

| Problem | What to do |
|---|---|
| Red triangle next to the mic, “Нет связи с сервером” | a VPN is on; turn it off or exclude «Кстати» from it |
| «На сегодня голосовые команды закончились» | daily voice limit reached; use the «+» button or wait until tomorrow |
| «Не понял» on a clear phrase | edit the transcript in the card and re-parse, or say one action per phrase |
| No email with the code | check spam; request the code again (it is valid for 15 minutes, 5 attempts) |
| Reminders do not arrive | allow notifications for the app and check that reminders are enabled in the defaults |
