# Матрица действий «Кстати»

Полный перечень того, что человек может сделать с записями в приложении: каждое действие — отдельная строка с кодом.
Файл служит двум целям: видеть, что уже умеет голос, и собирать под каждое действие примеры фраз.

Колонка «Голос»:

- **есть** — команда работает, примеры есть в обучающем наборе модели;
- **мало** — сервер команду выполнить умеет, но модель на ней почти не училась;
- **нет** — действие есть только в интерфейсе, голосом его выполнить нельзя.

Колонка «Карточек» — сколько карточек раздела «Обучение» собрано под действие (`server/train/scenarios.ts`).
Карточка показывает, что должно получиться, а фразу человек говорит своими словами.
У действий, которых голос не умеет, карточки помечены «сбор»: сверять ответ не с чем, фразы копятся на будущее.
Мало карточек там, где действие почти не варьируется («что посмотрим», «покажи мои заметки»).
