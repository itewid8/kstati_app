# Сборка двух приложений и выкладка сервера

Старое приложение «Кстати» (`mobile/`, `ru.wwp.app`, схема `kstati://`) и новое «Кстати β» (`mobile-prod/`, `ru.kstati.app`,
схема `kstatiapp://`) ставятся на один телефон рядом и работают с одним сервером.

## 1. Сервер (первым)

Изменения сервера обратно совместимы: старое приложение их не замечает (`server/test/compat-v1.ts`). Новому нужен API 2,
без него β покажет «Сервер устарел» и выключит подарки и архив тем.

```sh
cd ~/kstati
bash server-test.sh          # все тесты, включая compat-v1
```

Выкладка как обычно: изменения `server/` попадают в `main`, GitHub Actions разворачивает. Миграций базы нет: счётчик
`giftrev` живёт в той же таблице счётчиков. После выкладки `GET /health` отвечает `"api":2`.

## 2. Новое приложение «Кстати β»

```sh
cd ~/kstati/mobile-prod
npm install                                # expo-widgets и @expo/ui из β уже убраны, lock обновится
npm run typecheck                          # tsc --noEmit
bash scripts/test.sh                       # 205 тестов
```

iOS (бесплатный аккаунт Apple подходит: в β нет App Groups):

```sh
npx expo prebuild -p ios --clean
npx expo run:ios --device --configuration Release
```

Если Xcode просит подпись — открыть `ios/*.xcworkspace`, Signing & Capabilities → Team → свой аккаунт, запустить ещё раз.

Android:

```sh
npx expo prebuild -p android --clean
npx expo run:android --variant release
```

## 3. Старое приложение

Без изменений, как раньше:

```sh
cd ~/kstati/mobile
npx expo prebuild -p ios --clean          # app.config.js сам убирает виджет для iOS
npx expo run:ios --device --configuration Release
```

## 4. Проверка на телефоне после установки

Сценарии из отчётов агентов, которые на устройстве ещё не проверены:

1. Оба приложения рядом: разные имена и иконки, `kstati://` и `kstatiapp://` открывают каждое своё.
2. Вход по коду с почты; «Назад» на шаге кода ведёт к почте; выход и повторный вход — под экраном входа ничего не остаётся.
3. Колесо времени: инерция, щелчок на каждом шаге, 55 → 00 прибавляет час.
4. «Сделать планом», «Открыть план» из подзадачи, перенос периода плана — подзадачи стоят на месте, лишние помечены.
5. Голос: удержание и нажатие REC, «Удали йогу в субботу» → только этот раз, «Что я делаю на выходных?» → «Свободно».
6. `kstatiapp://record` при открытом приложении — только окно «Записать команду?».
7. Подарок с второго аккаунта: владелец не видит его, пока не отметит «получил».
8. Неделя: длинные слова в узких колонках обрезаются без многоточия.
9. Год с ~300 делами листается без задержек.

## 5. Что осталось открытым

- Токен входа лежит в файле состояния, который попадает в резервную копию iCloud (`docs/security/REVIEW-mobile-prod.md`, MP-1).
  Исправление — `expo-secure-store` (`npx expo install expo-secure-store`), токен из файла — в Keychain.
- Сервер не умеет отзывать токен при выходе (F8, MP-2).
- Вход через VK в β скрыт: сервер принимает возврат только на `kstati://`.
- «Этот и все следующие» есть при удалении повторяющегося дела, при правке меняется вся серия.
