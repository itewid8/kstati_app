# Обновление сервера и сборка двух приложений

Старое приложение «Кстати» (`mobile/`, `ru.wwp.app`, ссылки `kstati://`) и новое «Кстати β» (`mobile-prod/`, `ru.kstati.app`,
ссылки `kstatiapp://`) ставятся на один телефон рядом и работают с одним сервером. Порядок: сначала сервер, потом β.
Старое приложение пересобирать не нужно: новый сервер с ним совместим (`server/test/compat-v1.ts`).

## 0. Закоммитить изменения

Все файлы уже лежат в `~/kstati`. `mobile-prod/.env` (адрес сервера, без секретов) скопирован из `mobile/.env` и в git не попадает.

```sh
cd ~/kstati
git checkout redesign
git status                     # mobile-prod/, server/, design/, docs/, server-test.sh, .gitignore
git add -A
git commit -m "Редизайн: Кстати β, сервер API v2"
git push -u origin redesign
```

## 1. Сервер

Проверить локально (тесты идут без сети и без секретов):

```sh
cd ~/kstati
bash server-test.sh            # repeat, ideas, duration, v2, e2e, compat-v1 — все должны пройти
```

Выложить. Сервер разворачивается сам при push в `main`, если менялась папка `server/` (`.github/workflows/deploy-server.yml`).

```sh
git checkout main
git pull
git merge redesign             # вместе с сервером в main попадут mobile-prod/ и docs/ — это нормально
git push
```

Либо через GitHub: Pull request `redesign → main` → Merge.

Дальше GitHub → Actions → «Выкладка сервера»: зелёная галочка примерно через 3–5 минут. Последний шаг сам проверяет `/health`.

Проверить вручную, что сервер новый:

```sh
curl -s "$(grep '^EXPO_PUBLIC_API_URL' mobile/.env | cut -d= -f2)/health"
# в ответе должно быть "api":3
```

**API 3 — личный календарь.** Дело теперь принадлежит человеку и лежит в его разделе, группы видят его по правилам
видимости (`server/src/visibility.ts`). Старые дела группы переносятся владельцам сами при первой синхронизации группы
и остаются видны только своей группе. Старое приложение и прежние сборки β работают как раньше: видят дела групп,
личные дела им не видны. Сначала выложить сервер, потом ставить новую β.

Новых секретов, переменных и таблиц не нужно: настройки в GitHub и Lockbox остаются как есть, счётчик подарков живёт
в существующей таблице счётчиков.

Если что-то пошло не так — откат: GitHub → Actions → «Выкладка сервера» → прошлый успешный запуск → Re-run all jobs
(выкатит прежний образ), либо `git revert` слияния в `main` и `git push`.

## 2. Новое приложение «Кстати β»

```sh
cd ~/kstati/mobile-prod
npm install                    # своя папка node_modules; expo-widgets и @expo/ui уже убраны
npm run typecheck              # 0 ошибок
bash scripts/test.sh           # все тесты зелёные
```

### iPhone

```sh
npx expo prebuild -p ios --clean
npx expo run:ios --device --configuration Release
```

- Выбрать свой iPhone в списке. Если Xcode просит подпись: открыть `ios/*.xcworkspace` → цель приложения →
  Signing & Capabilities → Team → свой Apple ID → снова `npx expo run:ios --device --configuration Release`.
- На телефоне: Настройки → Основные → VPN и управление устройством → доверять своему Apple ID.
- С бесплатным Apple ID приложение работает 7 дней, потом его нужно пересобрать той же командой.
  Одновременно можно держать до 3 своих приложений — старое и β вместе помещаются.

### Android

```sh
npx expo prebuild -p android --clean
npx expo run:android --variant release
```

Телефон подключён по USB с включённой отладкой. Устанавливается рядом со старым приложением.

## 4. Что проверить на телефоне

1. Оба приложения рядом: разные имена и иконки, `kstati://` и `kstatiapp://` открывают каждое своё.
2. Вход по коду с почты; «Назад» на шаге кода ведёт к почте; выход и повторный вход — под экраном входа ничего не остаётся.
3. Удержание дела в списке, в дне, неделе и месяце, хотелки, «Смотреть», идеи — снизу окно быстрых действий;
   ЗАВТРА / +1 ЧАС / ВЫХОДНЫЕ переносят дело, у повторяющегося — только этот раз.
4. Бегущая строка: длинное название в списке через секунду едет по кругу без рывка; в колонках недели — обрезано.
5. Повторы при плохой связи: включить VPN или авиарежим, изменить пару дел, выключить — изменения дошли до второго телефона.
6. Колесо времени: инерция, щелчок на каждом шаге, 55 → 00 прибавляет час.
7. «Сделать планом», «Открыть план» из подзадачи, перенос периода плана — подзадачи стоят на месте, лишние помечены.
8. Голос: удержание и нажатие REC, «Удали йогу в субботу» → только этот раз, «Что я делаю на выходных?» → «Свободно».
9. `kstatiapp://record` при открытом приложении — только окно «Записать команду?».
10. Подарок со второго аккаунта: владелец не видит его, пока не отметит «получил».
11. Личный календарь: в выборе группы первой строкой «Личное» — там все мои дела. Дело с «Только я» не видно второму телефону.
12. Группа → «Мои дела в группе»: снять галочку у дела — оно пропало у второго участника; «Только выбранные» — пропало всё,
    кроме отмеченного; обратно на «Все» — окно «Показать группе все мои дела?».
13. Вступление по коду — сразу экран «Мои дела» с выбором режима, ГОТОВО ведёт дальше.
14. Окно своего дела — строка «ВИДНО»; у чужого дела участник (не админ) видит только окно ГОТОВО / НАПОМНИТЬ / КОПИЯ,
    админ группы может править, но не видимость.

## 5. Что осталось открытым

- Токен входа лежит в файле состояния, который попадает в резервную копию iCloud (`docs/security/REVIEW-mobile-prod.md`, MP-1).
  Исправление — `expo-secure-store`, токен — в Keychain.
- Сервер не умеет отзывать токен при выходе (F8, MP-2).
- Вход через VK в β скрыт: сервер принимает возврат только на `kstati://`.
- «Этот и все следующие» есть при удалении повторяющегося дела, при правке меняется вся серия.
