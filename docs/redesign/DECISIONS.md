# Решения по редизайну (пользователь, 2026-10-06)

- Новое приложение — папка `mobile-prod/`, id `ru.kstati.app`, имя «Кстати β». Старое `mobile/` не трогаем.
- Сервер один на оба приложения; все изменения обратно совместимы со старым приложением.
- Дизайн повторяется в точности: каждый экран сверяется с эталоном `design/reference/*.png` (≤ 2% на тему, см. design/README.md).
- Термин для дела с подзадачами — «План» (в макетах заменено «ОБЩЕЕ ДЕЛО» → «ПЛАН»).
- Перенос даты плана НЕ двигает подзадачи; вышедшие за период подсвечиваются «вне периода».
- Блок «Свободно» в ответе «что на выходных»: окна от 1 часа в интервале 09:00–22:00.
- Напоминания работают в обоих приложениях (двойные напоминания при двух установленных — допустимо, ничего не делаем).
