# Сервер

Пока умеет только голос: распознаёт речь (SpeechKit) и разбирает фразу (YandexGPT).
Аккаунты, группы и синхронизация появятся следующим этапом, до тех пор приложение
присылает нужный контекст (люди, записи) вместе с фразой.

## Первый запуск

```bash
cd ~/want_watch_plans/server
npm install
cp .env.example .env
open -e .env          # вставить API-ключ после YANDEX_API_KEY= и сохранить
```

## Проверить, как модель понимает фразы

```bash
npm run eval                                 # все ~40 фраз (модель из .env)
npm run eval -- дача                         # только фразы со словом «дача» — дешевле
YANDEX_MODEL=yandexgpt/latest npm run eval   # сравнить с Pro (дороже в ~6 раз)
```

Каждая строка: ✓ или ✗, время ответа, токены и, при ошибке, что не так и что ответила модель.
В конце — сколько токенов ушло и примерная стоимость прогона.

## Журнал запросов

Каждый запрос (голос, текст, eval) пишется строкой JSON в `logs/voice-ГГГГ-ММ.jsonl`:
фраза, длительность записи, ответ модели, итог, время, токены и примерная стоимость.
В журнале личные фразы — он не попадает в git.

```bash
npm run stats              # сводка за всё время
npm run stats -- 7         # за 7 дней
npm run stats -- 7 voice   # только голос с телефона (voice | text | eval)
```

## Запустить для приложения

```bash
npm run dev
```

В `mobile/.env` уже прописано `EXPO_PUBLIC_API_URL=http://10.0.2.2:3000` (адрес Mac из эмулятора).
После первого запуска сервера перезапустите Metro, чтобы приложение увидело адрес:
Ctrl+C в окне Metro → `npx expo start --dev-client` → открыть приложение.

Для настоящего телефона вместо `10.0.2.2` — IP вашего Mac в Wi-Fi
(Системные настройки → Wi-Fi → Подробнее → IP-адрес).

## Файлы

```
src/index.ts    HTTP: /health, /voice/text, /voice
src/prompt.ts   инструкция для модели и контекст (календарь, люди, записи)
src/parse.ts    проверка ответа модели и сборка результата для приложения
src/yandex.ts   вызовы SpeechKit и Foundation Models
src/audio.ts    m4a → OggOpus через ffmpeg (нужен только для /voice: brew install ffmpeg)
src/log.ts      журнал запросов
eval/run.ts     тестовые фразы
scripts/stats.ts сводка по журналу
```
